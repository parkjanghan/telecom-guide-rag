# KT 멤버십 앱을 업데이트 하면 업데이트를 할 수 없다고 오류가 발생합니다. 왜 그런거죠? (2)

분류: 자주하는 질문 > 멤버십 > 멤버십 혜택 > KT 멤버십 앱을 업데이트 하면 업데이트를 할 수 없다고 오류가 발생합니다. 왜 그런거죠? (2)

## 답변

업데이트 오류 (1)번의 문제가 아닌 경우 아래 조치방법으로 진행 부탁드립니다  
  
1. 스마트폰의 설정(또는 환경설정) 앱을 실행 합니다.  
(또는 상단 상태표시줄을 아래로 드래그 하여 알림창을 열어 설정 버튼 실행)  
2. 시스템관리자 > 애플리케이션 관리자 > 다운로드 메뉴의 설치되어 있는 앱 목록 중, 'KT 멤버십' 또는 'com.olleh.android.oc2' 앱이 있다면 선택한 후 상세화면에서 '삭제' 버튼 눌러 앱을 삭제 해주세요.  
*메뉴 진입방법 및 명칭은 휴대폰 모델에 따라 다를 수 있습니다.  
3. 다시 2번과 같은 시스템관리자 > 애플리케이션 관리자 > 다운로드 메뉴에서 '구글 플레이 스토어' 앱을 찾아서 상세화면으로 진입 후 '데이터 삭제' 버튼을 눌러 데이터를 삭제 해주세요.  
4. 이제 처음으로 돌아와 휴대폰의 구글 플레이 스토어 앱을 실행합니다.  
* 3번 과정을 정상적으로 진행하셨다면 구글 플레이 스토어 실행 시 처음 사용하시는 것 처럼 동의를 묻는 팝업이 뜹니다.  
5. 기본적인 동의 과정을 마치셨으면 구글 플레이 스토어의 검색창에서 'KT' 또는 'KT 멤버십' 을 검색 후 KT 멤버십 앱이 보이면 기존과 같이 [설치] 버튼을 눌러 설치 하시면 505 에러 없이 설치가 완료 되실 겁니다.
