# [인터넷전화] 지정번호 착신금지 서비스가 무엇인가요?

분류: 자주하는 질문 > 인터넷전화 > 통화서비스 > [인터넷전화] 지정번호 착신금지 서비스가 무엇인가요?

## 답변

스팸 방지 등을 위하여 특정번호의 착신을 제한하는 서비스입니다.  
  
ㆍ 요금 :  월 550원(부가가치세 포함)   
  
ㆍ 설정방법  
- 착신금지 번호설정 : * → 75 → 착신금지희망번호 → * → 통화  
- 착신금지 번호취소(개별) : # → 75 + 착신금지희망번호 → * → 통화  
- 착신금지 번호확인 : * → 78 → * → 통화  
- 착신 제한 가능 댓수 : 최대 20개 번호까지 등록하여 차단 가능  
- 착신금지 안내멘트 : 죄송합니다. 지금 거신번호는 상대방 고객님의 사정으로 이용하실 수가 없습니다.
