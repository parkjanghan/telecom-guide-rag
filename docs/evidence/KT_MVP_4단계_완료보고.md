# 4단계 실행·경계 검증

2026-10-23. 자동 테스트 82개 통과. 실제 원본 1,426개와 운영 색인을 보존하고 별도 임시 색인으로 검증했다.

| 점검 | 결과 |
|---|---|
| 같은 색인 두 번 실행 | 주제 103 / 근거 2,091 유지, 새 임베딩 0 |
| 청크 360·겹침 48 → 겹침 0 | 2,091 → 2,028건 |
| 청크 180·겹침 24 | 3,177건, 최대 입력 253토큰 |
| top-k 2 → 8 | 중복 제거 후 근거 3 → 5개, 대표 근거 2개 모두 유지 |
| 빈 검색 결과 반복 | 성공한 빈 결과 캐시 후 재요청 생략, 만료 후 재조회 |
| 실패한 외부 검색 | 실패를 정상 결과로 캐시하지 않음 |
| 동일 문서 재사용 | 임베딩·upsert 재실행 생략. 주제 추가 시 연결 갱신 |
| 키 누락 | 실제 HTTP 처리기 503/settings_not_ready, UI 안내 확인 |
| 색인 누락 | 실제 HTTP 처리기 503/index_not_ready, UI 안내 확인 |
| 주제 A → B → A | 브라우저에서 개별 질문·오류 대화 복원 확인 |
| 외부 Origin / 잘못된 요청 | 403 / 415 / 400 확인 |

키·색인 누락은 의존성을 주입한 격리 환경이며 사용자 .env를 수정하지 않았다. 주제 전환은 모델 응답 품질이 아닌 대화 분리·복원 검증이며, 키 누락 환경에서 질문과 오류 기록으로 확인했다.

수정: 성공한 빈 검색의 짧은 캐시, 동일 문서의 불필요한 재색인 방지, HTTP 서버 생성 함수 분리 및 실제 서버 포트 기준 Origin 검사. 회귀 테스트를 저장했다.
