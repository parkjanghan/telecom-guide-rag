# 개인사업자 회원가입 방법이 어떻게 되나요?

분류: 자주하는 질문 > 기타 > 회원가입 > 개인사업자 회원가입 방법이 어떻게 되나요?

## 답변

한국신용평가에 등록된 개인 사업자에 대해서만 회원 가입이 가능하며, 약관 동의 → 실명확인 → 회원정보 입력 단계를 거쳐 KT ID를 만들 수 있습니다.  
① 약관 동의 : KT ID 이용약관, 개인 정보 수집/이용 동의, 문자 메시지/이메일 마케팅(선택) 동의가 필요합니다.  
② 실명확인 : 상호, 사업자등록번호로 기가입 여부 확인 및 한국신용평가를 통한 사업장 실명 확인에 사용됩니다.  
③ 회원정보 입력 : 기본 회원 정보 외 업종, 업태 등 사업자 정보를 입력하셔야 하며, '사업자 회원 인증 절차'를 따라 사업자 인증을 받아야 가입이 완료됩니다.  
※ 휴대폰에서는 회원가입을 하실 수 없으며, 유선 kt.com(PC)에서 회원가입을 하시기 바랍니다. 자세한 문의는 고객센터(국번없이 100)로 연락주시면 됩니다.
