# 총액 결합할인 — 총액 결합할인 이런게 궁금해요!

분류: 상품 상세 > 결합상품 > 총액 결합할인 > 총액 결합할인 이런게 궁금해요!

- [Q질문

  다른 결합상품 간 전환이 가능한가요?](#accordions1-1 " 내용")
  <a id="accordions1-1"></a>

  A답변

  유무선 결합상품은 인터넷 한 회선당 하나에만 가입 가능하여, 타 결합상품(인터넷 뭉치면올레, LTE 뭉치면올레 등)에서 총액 결합할인으로 상품 변경은 가능합니다.
- [Q질문

  가구당 총액과 모바일 월정액 기여도(%)는 어떻게 계산이 되는 건가요 ?](#accordions1-2 " 내용")
  <a id="accordions1-2"></a>

  A답변

  가구에서 이용하는 모바일의 월정액을 모두 합하여 총액을 구합니다. (정지일수, 요금제 변경, 결합 상태 등을 모두 고려 일할 계산) 총액에서 모바일의 월정액이 차지하는 비중에 따라 모바일 월정액 기여도를 산정합니다.
- [Q질문

  모바일 월정액 기여도란?](#accordions1-5 " 내용")
  <a id="accordions1-5"></a>

  A답변

  예를들어, 인터넷 베이직과 모바일 2회선(요금제의 월정액이 부가세 포함 각각 5만원/10만원인 경우)을 이용하는 가구는 총액이 월정액 두 개를 더한 150,000원이 되고 총 할인금액은 27,610원으로 산정됩니다.  
  이때 월정액 10만원 요금제를 이용하는 고객이 총액에 기여를 더 많이 하였으므로 할인도 더 많이 받게 됩니다.  
  이것을 ‘모바일 월정액 기여도’라고 합니다.
- [Q질문

  월 중에 모바일 요금제나 인터넷 종류를 변경하면 어떤 기준으로 할인액이 산정되나요 ?](#accordions1-3 " 내용")
  <a id="accordions1-3"></a>

  A답변

  월 중 모바일 요금제 변경 시, 해당 요금제로 일할 되어 계산이 됩니다.  
  인터넷은 월 말 기준으로 이용하고 있는 상품에 따라 할인액이 계산됩니다.
- [Q질문

  할인액 테이블에서 인터넷 슬림에 해당하는 인터넷 종류가 어떻게 되나요 ?](#accordions1-4 " 내용")
  <a id="accordions1-4"></a>

  A답변

  할인액 테이블에서 인터넷 슬림으로 표기한 인터넷의 실제 상품은 아래와 같습니다.

  - 인터넷 슬림 : 인터넷 슬림, 인터넷 슬림플러스, 올레(다이렉트 포함), 라이트, 스페셜, 올라잇 인터넷
- Q질문

  인터넷 패밀리 회선도 결합할 수 있나요?

  A답변

  네, 결합 상품 가입 가능합니다.  
  단, 인터넷 패밀리 자회선(패밀리 인터넷으로 요금 할인을 받으시는 회선)의 경우 결합할인은 제공되지 않습니다. (인터넷 패밀리 자회선과 결합된 다른 상품에 제공되는 결합할인만 받으실 수 있습니다)
