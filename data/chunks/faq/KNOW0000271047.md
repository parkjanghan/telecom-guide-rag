# [My time plan] 해당 서비스는 어떤 서비스인가요?

분류: 자주하는 질문 > 모바일 > 데이터상품 > [My time plan] 해당 서비스는 어떤 서비스인가요?

## 답변

데이터 무제한이 아닌 LTE 요금제 이용 고객이 가입 후 원하는 시간을 직접 선택하면 해당시간대에 3시간 동안 데이터를 무제한으로 이용할 수 있는 서비스로 출퇴근 시간대나 특정 시간대에만 데이터를 이용하는 고객님에게 유리한 상품입니다.

선택한 시간대에 매일 2GB의 기본 데이터가 제공되고, 제공량 모두 사용 시 최대 속도 3Mbps로 데이터 무한 이용 가능하여 다른 데이터 상품 대비 경제적입니다.
