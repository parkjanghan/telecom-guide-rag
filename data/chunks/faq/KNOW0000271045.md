# 데이터쉐어링의 데이터 사용량은 어떻게 확인할 수 있나요?

분류: 자주하는 질문 > 모바일 > 데이터상품 > 데이터쉐어링의 데이터 사용량은 어떻게 확인할 수 있나요?

## 답변

데이터쉐어링의 사용량은 KT닷컴, 마이케이티 앱, 고객센터에서 확인 가능합니다.  
  
ㆍ KT닷컴 → 마이 → 가입/이용/해지 → 이용량/이용내역 → 이용량 조회/충전  
[☞ 바로가기 클릭](https://my.kt.com/usage/MoUsageList.do)  
ㆍ 마이케이티 앱 → 메뉴 → 마이 →가입/이용/해지 → 이용량/이용내역 → 이용량 조회/충전
