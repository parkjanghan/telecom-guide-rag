# [KT 패밀리박스] 데이터 담기와 꺼내기는 용량과 횟수 제한 없이 이용 가능한가요?

분류: 자주하는 질문 > 혜택 > 패밀리박스 > [KT 패밀리박스] 데이터 담기와 꺼내기는 용량과 횟수 제한 없이 이용 가능한가요?

## 답변

아닙니다. 데이터 꺼내기는 용량 제한이 없으나,

데이터 담기는 번호당 월 최대 2,000MB까지만 가능합니다.

또한, 담기와 꺼내기를 합산하여 월 30회까지만 이용 가능합니다.

담기 및 꺼내기 데이터 단위는 아래와 같습니다.

- 담기 : 100MB~2,000MB 범위 내에서 100MB 단위로 담기 가능

- 꺼내기 : 100MB~2,000MB까지 100MB 단위로  원하는 용량을 한번에 꺼내 이용 가능
