# 데이터충전은 어떤 서비스인가요?

분류: 자주하는 질문 > 모바일 > 데이터상품 > 데이터충전은 어떤 서비스인가요?

## 답변

데이터충전 서비스는 데이터가 부족할때 쉽게 충전해서 이용하는 1회성 충전 상품입니다.  
  
[데이터충전 신청 방법]  
 ㆍ KT닷컴 → 상품서비스 → 모바일 → 부가서비스 → 데이터 → 데이터충전  
[☞ 바로가기 클릭](https://product.kt.com/wDic/productDetail.do?ItemCode=1287)  
   ㆍ 마이케이티 앱 → 메뉴 → 상품서비스 → 모바일 → 부가서비스 → 데이터 → 데이터충전
