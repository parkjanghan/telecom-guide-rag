# [데이터] 데이터를 다 썼을 때 어떻게 하죠?

분류: 자주하는 질문 > 기타 > 기타 > [데이터] 데이터를 다 썼을 때 어떻게 하죠?

## 답변

데이터를 모두 사용했다면 충전하여 이용할 수 있습니다.  
  
[데이터충전]  
ㆍ 기본 제공 데이터 사용 후 추가 데이터를 즉시 충전하는 1회성 충전 서비스   
ㆍ 멤버십으로  80% 할인받아 충전 가능

▶ 멤버십 충전은 월 3회까지만 이용 가능  
  
[LTE 데이터쿠폰]  
ㆍ 데이터가 필요할때 충전하여 이용할 수 있는 선불형 쿠폰  
ㆍ 온/오프라인에서 간편하게 구매하여 등록 후 이용 가능  
ㆍ 쿠폰 등록 후 1년까지 이용   
  
[LTE 데이터룰렛]  
ㆍ 월말 데이터가 부족하면 매월 25일부터 룰렛 돌린 후 이용   
ㆍ 멤버십으로 최대 1GB까지 당첨 가능   
  
[장기고객쿠폰]  
ㆍ 사용기간에 따라 연 1회 최대 10장 쿠폰 제공  
ㆍ 제공된 쿠폰 중 데이터 2GB 쿠폰 사용 가능
