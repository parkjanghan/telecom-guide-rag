# 통합요금제 이용 중에도 데이터 추가 충전이 가능한가요?

분류: 자주하는 질문 > 모바일 > 부가서비스 > 통합요금제 이용 중에도 데이터 추가 충전이 가능한가요?

## 답변

통합요금제에서도 데이터가 부족할 때 유료 결제 또는 KT 멤버십으로 필요한 데이터를 구입하여 이용 가능합니다.  
  
ㆍ 100MB : 1,000원 (멤버십 이용 시 200원)  
ㆍ 1GB : 7,000원 (멤버십 이용 시 1,400원)  
ㆍ 5GB : 15,000원 (멤버십 이용 시 3,000원)  
  
▶ KT 멤버십 충전은 월 3회까지만 이용 가능
