# 임대폰 서비스란 무엇인가요?

분류: 자주하는 질문 > 모바일 > 서비스정책 > 임대폰 서비스란 무엇인가요?

## 답변

휴대폰 분실이나 고장/파손으로 사용을 못하는 고객님들을 위해 임대폰을 대여해 드리는 서비스 입니다.  
고장/파손의 경우 신분증 지참 후 가까운 M&S 대리점 또는 KT플라자로 방문 시 대여 가능하며, 분실 임대폰은 KT닷컴에서도 신청 가능합니다.  
  
[KT닷컴에서 임대폰 신청하기]  
ㆍ KT닷컴 → 마이 → 가입/이용/해지 → 가입정보 변경 → 분실신고/해제 → 임대폰 신청  
[☞ 바로가기 클릭](https://my.kt.com/lostas/MoLeasePhoneInfo.do)  
  
[가까운 KT플라자/대리점 위치 찾기]  
ㆍ KT닷컴 → 고객지원 → 매장/고객센터 → 매장 찾기  
[☞ 바로가기 클릭](https://help.kt.com/store/KtStoreSearch.do)
