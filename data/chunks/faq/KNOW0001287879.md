# 베이직1.4GB 요금제 사용 중인데 초과요금이 나올까봐 걱정이에요.

분류: 자주하는 질문 > 모바일 > 요금제 > 베이직1.4GB 요금제 사용 중인데 초과요금이 나올까봐 걱정이에요.

## 답변

영상/부가통화가 50분 제공되며, 초과 이용 시 통화 요금이 발생합니다.  
초과 사용 시 음성 1.98원/초, 영상 3.3원/초로 요금이 발생됩니다.

데이터 기본 제공량 모두 사용 후 최대 400Kbps 속도로 이용 가능합니다.
