# 요고 모바일 — 위버스 유의사항 및 혜택 이용 방법

분류: 모바일 > 요고 모바일 > 위버스 유의사항 및 혜택 이용 방법

- 일반 유의사항
  - 위버스를 이용 하려면 서비스 제공사의 이용약관, 개인정보 수집 이용 및 기타 정책에 동의해야 합니다.
  - 위버스 이용 관련 내용은 위버스 이용약관을 확인하시기 바랍니다. ([https://weverse.io/policies/terms](https://weverse.io/policies/terms "새창열림"))
- 위버스 혜택 이용 주의사항
  - 위버스 젤리 이용에 대한 정책은 위버스 이용약관에 따릅니다. 위버스 젤리 이용 유의 사항을 꼭 확인하세요. [자세히 보기](https://go.weverse.io/RM44/kt3 "새창열림")
  - 위버스 젤리 혜택을 이용하기 위해서는 위버스 가입 및 KT홈페이지 또는 안내 문자 등을 통한 위버스 젤리 쿠폰 등록이 필요합니다.
  - 위버스 젤리 쿠폰은 제공일로부터 다음 달 말일 까지 위버스 디지털 코드 등록 메뉴에서 등록 가능합니다.
  - 위버스 젤리 쿠폰은 1회에 한해 등록 가능하므로, 타인에게 제공하지 마세요.
  - 쿠폰 등록 시, 위버스 젤리가 적립되며, 적립된 젤리는 쿠폰 제공일로부터 다음 달 말일 까지 이용 가능합니다.
  - 위버스 혜택을 가입한 다음 달 부터는 매월 1일 08시 기준으로 위버스 혜택을 이용 중인 경우, 젤리 쿠폰을 제공합니다.  
    (요금제 이용 정지 시에는 젤리 쿠폰이 제공되지 않으며, 정상 이용하시는 시점에 젤리 쿠폰을 제공합니다.)
  - 위버스 혜택을 가입한 달에는 아래와 같이 젤리 쿠폰을 제공합니다.
    **표 설명:** 위버스 혜택 가입한 달 젤리 쿠폰 안내 표, 구분, 요고 69/61, 요고 55 등으로 구성함

| 구분 | 구분 | 요고 69/61 | 요고 55 |
| --- | --- | --- | --- |
| 초이스 혜택으로  <br>위버스를 선택한 달 | 1~15일 내 가입 시 | 젤리 40개 | 젤리 20개 |
| 초이스 혜택으로  <br>위버스를 선택한 달 | 16일~말일 내 가입 시 | 젤리 20개 | 젤리 10개 |
| 초이스 혜택으로  <br>위버스를 선택한 다음달 부터 | 매월 1일 | 젤리 40개 | 젤리 20개 |
- 위버스 젤리 혜택 받는 방법

  ‘KT 위버스 젤리 쿠폰’을 위버스 디지털 코드 입력 메뉴에서 등록 하신 후 이용 가능합니다.

  젤리 쿠폰은 쿠폰 제공일로부터 다음 달 말일까지 등록 가능합니다.  
  쿠폰 등록 시, 위버스 계정에 젤리가 적립되며,쿠폰 제공일로부터 다음 달 말일 까지 이용 가능합니다.

  ※ 쿠폰 등록 완료 후 ‘위버스 > 더보기 > 젤리 조회’에서 적립된 젤리를 확인하실 수 있습니다.

  ![STEP 2](https://product.kt.com/static/prodetail/1652/common/images/w-step1-label-2.png)   **위버스 젤리 쿠폰 등록하기**

  위버스 기존 고객

  위버스 계정을 이미 보유하신 경우

  1. **단계 1** 보유하신 위버스 계정 중  
     위버스 젤리를 받고 싶은 계정으로 로그인을 진행해주세요.
  2. **단계 2**쿠폰번호를 입력하고 ‘등록하기’ 버튼을 누르세요. (쿠폰번호가 자동 입력된 경우, 받으신 쿠폰번호와 동일한지 확인하세요)
  3. **단계 3**등록할 계정과 젤리 개수를 확인하고 ‘확인’ 버튼을 눌러주세요.
  4. **단계 4**지급된 젤리를 확인하세요. 원하시는 구독 상품을 자유롭게 이용하세요.

  위버스 신규 고객

  위버스 계정이 처음이시거나, 새롭게 위버스 계정을 만들고 싶은 경우

  1. 단계 1위버스 계정으로 사용할 이메일 주소를 입력한 뒤 ‘이메일로 계속하기’ 버튼을 누르세요.
  2. 단계 2이메일 주소를 확인하고 ‘가입하기‘ 버튼을 누르세요.
  3. 단계 3비밀번호를 입력한 뒤 ‘다음’ 버튼을 누르세요.
  4. 단계 4닉네임 설정, 이용약관을 동의하시면 이메일 인증을 안내드려요.
  1. 단계 5등록하신 이메일 계정에서 이메일 인증을 해주세요.
  2. 단계 6이메일 인증이 완료되면 ‘로그인으로 돌아가기‘ 버튼을 눌러주세요.
  3. 단계 7가입하신 위버스 계정으로 로그인을 진행해주세요.
  4. 단계 8쿠폰번호를 입력하고 '등록하기'버튼을 누르세요. (쿠폰번호가 자동 입력된 경우, 받으신 쿠폰번호와 동일한지 확인하세요.)
  1. 단계 9등록할 계정과 젤리 개수를 확인하고 ‘확인’ 버튼을 눌러주세요.
  2. 단계 10지급된 젤리를 확인하세요. 원하시는 구독 상품을 자유롭게 이용하세요.

  ![STEP 3 계정 생성 완료 후](https://product.kt.com/static/prodetail/1652/common/images/w-step3-label-3.png)   **위버스 젤리 적립 내역 확인 하기**

  위버스 젤리 조회 페이지에서 적립된 젤리를 확인할 수 있습니다.

  1. **단계 1** 위버스 앱 > 더보기 > 젤리 버튼을 눌러 젤리 조회 페이지로 접속하세요.
  2. **단계 2**젤리 조회 페이지에서  
     적립된 젤리를 확인하세요.
  3. **단계 3**KT 위버스 초이스 혜택으로 받은 젤리임을 확인하세요.
