# 초이스 요금제는 데이터 속도 제한이 없나요?

분류: 자주하는 질문 > 모바일 > 요금제 > 초이스 요금제는 데이터 속도 제한이 없나요?

## 답변

언제 가입하시더라도 속도,용량 제한 없이 완전 무제한으로 이용 가능합니다.   
단, 스마트기기에서 이용하는 공유데이터는 별도 제공량에서 이용할 수 있습니다.

ㆍ 초이스 더블 : 90GB 별도 제공 + 최대 200Kbps 속도로 계속 사용  
ㆍ 초이스130 : 100GB 별도 제공 + 최대 200Kbps 속도로 계속 사용  
ㆍ 초이스110 : 80GB 별도 제공 + 최대 200Kbps 속도로 계속 사용  
ㆍ 초이스90 : 60GB 별도 제공 + 최대 200Kbps 속도로 계속 사용
