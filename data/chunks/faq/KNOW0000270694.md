# 데이터투게더는 어떤 요금제인가요?

분류: 자주하는 질문 > 모바일 > 요금제 > 데이터투게더는 어떤 요금제인가요?

## 답변

스마트폰(요금제)와 데이터 공유가 가능한 요금제로 대상 기기에 따라 요금제로 구분됩니다.(부가가치세 포함 금액)  
  
ㆍ 데이터투게더Watch : 스마트폰(요금제)와 음성/문자/데이터까지 공유가 가능한 워치 전용 요금제   
   - 월정액 11,000원  
   - 제공데이터 : 500MB  
  
ㆍ 데이터투게더1GB : 스마트폰(요금제)와 데이터 공유가 가능한 전용 요금제   
   - 월정액 11,000원  
   - 제공데이터 : 1GB  
  
ㆍ 데이터투게더3GB : 스마트폰(요금제)와 데이터 공유가 가능한 전용 요금제   
   - 월정액 19,800원  
   - 제공데이터 : 3GB
