## 서비스 동작

- 일반 선택 목록과 자동 선별용 모델 카탈로그에서는 두 주제를 제외한다.
- 별도의 ‘근거 준비 중인 주제 2개’ 영역에는 이름과 사유만 표시하며 선택 버튼은 제공하지 않는다.
- 직접 API로 해당 ID를 보내도 `topic_unavailable`로 차단한다. 자동 모델이 목록에 없는 해당 ID를 추측해 반환해도 차단한다.
- 과거 대화는 삭제하지 않는다. 해당 주제의 저장 대화는 읽을 수 있지만 새 질문 전송은 막도록 UI 처리했다. 이 기존 기록 복원 경로의 별도 브라우저 시나리오는4단계 검증에 남긴다.
- 사용자에게 보이는 지원 수는101개, 준비 중2개로 구분한다. 지원101개는 최소 대표 근거가 연결됐다는 뜻이며 정책 전체의 정확도 인증은 아니다.
- 조사용 원본 메타데이터와 내부 색인103개는 유지한다. 내부 검색 CLI는 조사 자료까지 다루므로 챗봇의 지원 목록과 구분한다.

## 검증

- 기존61개+신규7개 = 자동 테스트68개 통과.
- 실제101개 지원 주제 모두 primary_chunk_ids가 있고, 최소 하나의 품질 격리되지 않은 대표 근거가 있음을 검사했다.
- 목록 분리·자동 카탈로그 제외·직접 요청 차단·모델의 미지원 ID 추측 차단을 테스트했다.
- 실제 HTTP 검증: 지원101/미지원2, 두 ID 직접 요청 모두422 topic_unavailable.
- 브라우저에서 ‘재약정’ 필터에 선택 버튼이 없고, 준비 중 영역에 두 주제가 표시되는 것을 확인·캡처했다.
- JavaScript 문법 검사 통과.
- 메타데이터 변경에 맞춰 재색인 완료:103개/2,091개 유지, 신규 임베딩0개·캐시2,194개 재사용.
- 이번 검증에서는 실제 생성 모델을 호출하지 않았다.

사용 중인8765서버를 종료하지 않고8766임시서버에서 검증했다. 임시서버는 검증 후 종료한다. 실제 사용 서버는 Ctrl+C 후 기존 run-chat.ps1 명령으로 재시작해야 변경이 반영된다. 재색인은 이미 실행했다.

## 전체 계획 점검

1단계와2단계 완료. 다음은3단계 ‘탐색 메타데이터와 공식 문서 종류를 근거 영역에 구분 표시’다. 순서는 유지한다.
