# 요구사항과 현재 적용 범위

기준: AI코어프로젝트 2회차 요구사항정의서 23쪽, 2026-10-23 재점검. 최초 감사는 수정 전 상태이며 현재 판정은 validation.md를 따른다.

| 구분 | 현재 구현 및 확인 범위 |
|---|---|
| F2001~2002 | 메타데이터 103건, 지원 101건/근거 미확보 초안 2건 분리. item_id 기반 upsert와 반복 건수 검증 |
| F2003 | 질문·최근 대화·선택 주제의 범위를 포함한 독립 검색어 생성 |
| F2004 | 공식 후보 검색 → LLM 선별 → 본문 수집/저장 공식 묶음 대체. 지원 주제 대표 근거 우선 포함 |
| F2005~2006 | 주제/근거 컬렉션 분리, 크기·겹침·top-k 설정, 출처·버전·주제 연결, 중복 제거 |
| F2007~2008 | LangGraph retrieve/generate 2노드, 탐색정보와 공식 유형 분리, 사용한 인용만 표시 |
| F2009~2012 | 주제별 대화 복원, 납부 변경 특화 질문, 자연어 조건 카드, 진행·오류·키/색인 안내 |
| 심화 F2013~2016 | 직접 UI, MMR 선택/비교, 5문항 RAG 전후 실측, FAQ·가이드·상품·약관 유형 표시 |

사용자와 합의한 조정: 프레임워크 기본 UI 대신 HTML/CSS/JS로 ChatGPT와 유사한 UI를 구성했다. GMS Responses를 httpx로 호출하며 지정 모델 gpt-6.1-sol을 유지한다. PDF에 예시·필수 라이브러리로 열거된 전체 스택과 설치 목록이 일치하지 않는다. requirements.txt가 실제 사용 목록이며, 수업에서 특정 패키지 자체를 평가한다면 담당자 확인이 필요하다. 사용하지 않는 패키지를 설치한 것으로 제출하지 않는다.

문서에 직접 없는 결론도 관련 정책을 종합하여 조건부로 판단할 수 있다. 이때 직접 명시되지 않았다는 문장을 반드시 붙인다. 자동 검사는 인용 문자열·ID·고지 형식이며, 논리적 타당성 전체를 보증하지 않는다.

완료로 표시하지 않는 항목: 출처별 저장·재배포 허용 근거(NF2007), 응답 시간에 대한 사용자 수용성(NF2001), 다른 교육생의 실제 상호검증. 27개 주제의 범위 보완과 자료 최신성은 검토 대상이다.
