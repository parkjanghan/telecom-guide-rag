# 요고 모바일 — VIP 멤버십/추가 데이터 제공 프로모션

분류: 모바일 > 요고 모바일 > VIP 멤버십/추가 데이터 제공 프로모션

**① 멤버십 VIP 혜택**

- 대상 요금제 및 혜택 제공 기간
  - ① 26.1.5~26.12.31 내 요고 49/46/44/42 가입 시, 요금제 가입일로부터 12개월 간 제공
  - ② 25.7.1~26.1.4 내 요고 69/61/55/49/46/44/42/40 가입 시, 25.8.1~26.6.30까지 제공
  - ③ 25.1.1~25.6.30 내 요고 69/61/55/49/46/44/42/40 가입 시, 25.2.1~25.12.31까지 제공
  - ④ 24.8.1~24.12.31 내 요고 69/61/55/49/46/44/42/40 가입 시, 24.9.1~25.6.30까지 제공
  - ⑤ 24.1.19~24.7.31 내 요고 69/61/55/49/46/44/42/40 가입 시, 24.2.16~24.12.31까지 제공
    - ※ 요고 69/61/55 가입 고객님은 요금제 이용 기간 동안 멤버십 VIP 등급을 지속 제공합니다. 혜택 제공 기간이 경과되어 멤버십 VIP 등급 혜택이 종료된 고객님은 26.2.1자로 멤버십 VIP 등급이 부여됩니다.
- VIP 등급 제공 시점 : 1일~15일 내 가입 시 다음달 1일, 16일~말일 내 가입 시 다음달 16일에 VIP 등급이 부여됩니다.

**② 추가 데이터 혜택**

- 대상 : 24.1.19~26.1.4 내 요고 44/42/40/38/36/34/32/30을 가입하신 고객님
- 혜택 : 추가 데이터를 요금제 가입 시점으로부터 최대 12개월간 제공
- 추가 데이터 제공
  **표 설명:** 요금제, 월정액, 데이터(기본 제공, 데이터 추가 프로모션(12개월 간 제공(추가제공, 총 데이터)), Y고객 이신 경우(데이터 추가 프로모션+ Y덤(추가제공, 총 데이터)))로 정의한 표
