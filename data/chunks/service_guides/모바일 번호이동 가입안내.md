# 모바일 번호이동 가입안내

분류: 서비스 안내 > 상품가입 > 모바일 번호이동 가입안내

## 번호이동성제도란?

고객님께서 이동통신 회사를 변경하시더라도 기존에 사용하던 식별번호를 포함한 모든 번호를 변경을 원하는 이동통신회사에서 그대로 사용할 수 있는 제도입니다.

**표 설명:** 대상고객, 신청장소 및 방법, 비용, K-bank의 순서로 번호이동성제도란?에 대한 설명 정보표

| 항목 1 | 항목 2 |
| --- | --- |
| 대상고객 | - 번호이동 희망고객 (단, 다음의 고객은 번호이동이 제한됩니다.)<br>  - 요금 연체고객 및 선불요금제 이용고객<br>  - 임대폰 이용고객 |
| 신청장소 및 방법 | - 대리점에 직접 방문 후 신청(법정대리인도 가능)<br>  기존 사업자에서 미리 해지하시면 안됩니다.<br>- 가입신청서 작성시 기존 핸드폰 일련번호 뒷 4자리 또는 납부방법에 따른 계좌번호 뒷 4자리 또는 카드번호 끝4자리 기재필 |
| 비용 | - 가입비 : 0원<br>- 번호이동 수수료 : 800원(부가세 별도)<br>- 번호이동 전 사업자의 납부하실 금액 |
| K-bank | - 휴대폰 교체 필요<br>- 번호이동 전 사업자의 잔여 할부금은 완납 또는 할부 지속 선택 가능<br>- 번호이동 한 고객은 3개월간 번호 이동 금지됨 |

## 번호이동 방법

예) SKT 고객이 KT로 번호 이동할 경우

1. 1. 대리점 방문
2. 2. 가입신청서 작성
3. 3. SKT사용 당월 미납금액 납부
4. 4. 핸드폰/요금제 선택
5. 5. 개통

**표 설명:** 구분, 내용의 순서로 번호이동 방법 정보표

| 구분 | 내용 |
| --- | --- |
| 본인 | - 가입고객 신분증 |
| 대리인 | - 가입고객 신분증, 가입고객 인감증명서, 가입고객 인감도장이 날인된 위임장,대리인 신분증 |
| 개인사업자 | - 대표자 신분증, 사업자 등록증 사본 |
| 법인 | - 사업자등록증 사본, 법인인감증명서, 법인인감도장이 날인된 위임장, 대리인 신분증 |

## 번호이동 신청가능 시간

- 월~금요일 : 10~20시
- 토요일/일요일/공휴일 : 휴무

### 알려드립니다.

- 구형 운전면허증(2002년 6월 30일 이전발급)은 고객 신분 확인용으로 사용불가
- 주민등록번호, 가족관계증명서 중 택 1 (2가지 서류 모두 가족관계확인이 가능해야 함) / 위임장 : 발급일로부터 3개월
- 인감증명서 : 발급일로부터 3개월
