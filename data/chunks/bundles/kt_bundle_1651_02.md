# KT 인터넷 - MVNO 이동전화 결합 — MVNO 이동전화 결합 시, KT 인터넷 할인액

분류: 상품 상세 > 결합상품 > KT 인터넷 - MVNO 이동전화 결합 > MVNO 이동전화 결합 시, KT 인터넷 할인액

부가세가 포함된 실제 지불금액입니다.

**표 설명:** 요금안내 표, 상품명, 월정액, 데이터 등으로 구성함

| 구분 | 할인액 |
| --- | --- |
| 인터넷 슈퍼프리미엄 | 16,500원 |
| 인터넷 베이직/에센스/프리미엄/프리미엄 플러스 | 11,000원 |
| 인터넷 슬림플러스 | 9,350원 |
| 인터넷 슬림 | 3,300원 |

- 상기 할인액은 부가세(VAT)가 포함된 금액입니다.
- 인터넷은 신규 가입 시점(개통 완료일 기준)부터 익월 말까지 결합 가능합니다. (최대 1회선)
- 인터넷 상품이 '싱글 인터넷 베이직'인 경우 5,500원 결합할인(3년 약정 기준)이 제공됩니다.
- 상기 금액은 3년 약정 기준이며, 2년 약정의 경우 1/2할인액, 1년 약정의 경우 상기의 1/4을 제공합니다.
- 가입완료 처리까지 영업일 기준 1~2일 소요되며, 월말 가입 신청 시 결합할인이 익월부터 제공될 수 있습니다.
- 인터넷 패밀리 요금제 할인, 복지 감면 등 개별 서비스에서 제공하는 할인/감면과는 중복 적용하지 않습니다.
- KT 홈/비즈 결합상품에 중복가입 시, KT 홈/비즈 결합할인을 우선 적용하며 중복 할인되지 않습니다.
  - 단, KT 홈 결합 중 '유선결합'인 경우는 상기 인터넷 할인을 우선 적용합니다. (중복할인 불가)
