# 선불요금제(충전식) 이용 시 국제전화 발신시에도 충전금액에서 차감되나요?

분류: 자주하는 질문 > 모바일 > 요금제 > 선불요금제(충전식) 이용 시 국제전화 발신시에도 충전금액에서 차감되나요?

## 답변

이용 가능한 국제전화 번호는 '001, 002, 005, 008, 00300, 00345, 00350, 00365, 00388, 00700, 00727, 00761, 00766, 1678'이며, 통화 종료 후 현재 잔액에서 즉시 차감됩니다.

잔여 충전 잔액만큼만 사용 가능하며, 잔액만큼 통화하면 자동 종료 됩니다.
