# 6단계 비교 평가·제출 문서 정리

동일 질문 5개에 대해 문서 미제공/RAG 제공을 실제 GMS로 실행하고 사실성·근거·모름 처리로 검토했다. 5개 모두 인용 검사를 통과했다. 독립 정답률 평가는 아니다.

명의변경 1건의 가능 범위 설명 부족을 발견해 관련 FAQ를 대표 근거로 추가했다. 원본 청크는 보존하고 재색인했으며 새 임베딩은 0개였다. 보완 후 답변과 대표 근거 보존 결과를 별도 파일에 남겼다. 원래 비교 로그를 성공 사례로 덮어쓰지 않았다.

repo docs에 요구사항·파이프라인(Mermaid 그림)·비교 평가·검증/셀프점검표·상호점검표와 증빙을 모았다. README와 오래된 지원 주제 건수도 갱신했다. 실제 상호점검은 미실시로 표시했다.

기술 보완과 자체 실행·문서 정리는 1~6단계 완료. 출처 이용 허가(NF2007), 시간 수용성(NF2001), 특정 필수 패키지 평가 방식, 교육생 상호검증은 사람의 확인이 남는다. 전체 요구사항 전부 통과라고 표시하지 않는다.

다음 사용: 기존 서버 재시작 후 run-chat.ps1로 실행하고 최초 질문과 명의변경 질문을 확인한다. 사용자 서버/키/.vscode는 변경하거나 종료하지 않았다. 커밋·푸시하지 않았다.
