# telecom-guide-rag

KT 공식 자료를 검색해 근거와 함께 답하는 로컬 상담 챗봇입니다.

**실행:** PowerShell에서 `./run-chat.ps1` → http://127.0.0.1:8765

[챗봇 사용·설정·검증 안내](CHATBOT.md) | [검색/색인 안내](RETRIEVAL.md)

LangGraph retrieve/generate, 상담 주제 선택, 조건 탐색, 납부 변경 상황 점검, 외부 공식 후보 검색·캐시, 인용 검사와 ChatGPT 스타일 UI를 제공합니다.

- `data/chunks/service_guides/`: 서비스 안내 메뉴별 MD 21개.
- `data/chunks/faq/`: 질문·답변별 MD 1,043개.
- `data/SOURCES.md`: 각 MD의 원본 URL, 분류 경로, 청킹 범위와 수집일.
- `data/raw/`: 기존 공식 PDF 15개(로컬 보관, Git 제외).

FAQ와 서비스 안내는 청크 MD만 보관합니다. 중복 추출 MD·HTML·목록 응답·로컬 이미지는 제거했으며 본문 이미지는 공식 URL을 참조합니다. 원문의 문구·표·조건을 유지하고, 원문의 정책이 현재도 적용되는지 검토하기 전이므로 draft로 관리합니다. 수집일은 시행일을 뜻하지 않습니다. 청크 사이의 의미 관계는 아직 추가하지 않았습니다.

공개 FAQ 11개 분류의 목록 108페이지를 순회했고, 분류별 고유 FAQ 수와 표시 건수가 일치함을 확인했습니다. FAQ 1,043개와 서비스 안내 21개에서 MD 변환 시 본문 텍스트 보존을 확인했습니다. 검증은 추출에 관한 것으로 RAG 검색·답변 정확도 평가와 구분합니다.

## 상품 상세 추가 수집

- `data/chunks/bundles/`: 공식 결합상품 12개의 상세 절별 청크 45개.
- `data/chunks/payment_benefits/`: KT 제휴카드 안내 21개와 공통 안내 1개, 총 22개.

각 파일의 공식 페이지, 실제 추출 HTML 주소, 상세 절과 청킹 범위는 `data/SOURCES.md`에 기록했습니다. 표 27개와 원문 텍스트·이미지 대체텍스트의 보존을 확인했습니다. 제휴카드는 KT 안내 페이지 범위이며 카드사 상세 약관·프로모션은 미수집입니다. 카드별 세부 혜택 판단에는 후속 자료가 필요합니다.

## 핵심 요금제·할인·약관 추가

- `data/chunks/mobile_plans/`: 주요 요금제 8개 상품의 상세·연령별 혜택 151개 청크.
- `data/chunks/discounts/`: 정책 안내 2개 및 복지·덤 혜택 가이드 5개, 총 7개 청크.
- `data/chunks/terms/`: 약관 원본 8개에서 선택한 162쪽 범위의 핵심 청크 137개.
- `data/EXTERNAL_LOOKUP.md`: 특수 요금제·카드 상세·변동 프로모션·양식의 외부 조회 기준.

이번 추가는 295개 MD입니다. 원문 URL·정확한 추출 범위·PDF 페이지는 `data/SOURCES.md`에 기록했습니다. PDF 전체를 내부 청킹한 것으로 간주하지 않습니다. 약관은 표와 조항 경계 검토 전인 draft이며 2개 청크에는 PDF 전용 글리프 검토 표시가 있습니다. 특수 요금제 26개와 제휴카드 상세 조건·양식은 외부 조회로 관리합니다. 실시간 조회·캐시·후보 선별을 연결했습니다. 접근 제한 시 저장 자료를 사용하거나 확인 불가로 안내합니다. 자세한 범위는 CHATBOT.md를 참고하세요.

## 상담 주제 메타데이터

`data/topics/`에 독립 상담 목적 103개의 검색용 메타데이터 초안을 정리했습니다. 주제별 별칭·대표 질문·조건·범위·index_text와 원문 연결 180개(고유 청크 175개)를 포함합니다. 대표 근거 연결 초안 74개, 범위·근거 보완 필요 27개, 공식 근거 미연결 2개이며 모두 draft입니다. 주제 메타데이터는 탐색용이고 공식 정책 근거를 대체하지 않습니다.

전체 목록과 상태는 `data/topics/README.md`, 형식은 `data/topics/SCHEMA.md`를 참고하세요. 대표 질문은 작성 예시이며 독립 평가 질문이 아닙니다. 원문 1,426개는 변경하지 않았습니다. 주제·원문의 두 컬렉션과 로컬 임베딩 검색 프로토타입을 구성했습니다. 주제는 초안이며 LLM 답변 생성과 LangGraph를 연결했습니다. 독립 질문 전체 정확도 평가는 별도입니다. 과거 100개 선정안과 게시판 검증 기록은 이력으로 보존합니다.

## 로컬 검색 프로토타입

실행 방법은 [RETRIEVAL.md](RETRIEVAL.md)를 참고하세요. `run.ps1 audit`, `run.ps1 index`, `run.ps1 search "질문"`으로 데이터 확인·색인·검색을 실행할 수 있습니다. 현재 PC의 로컬 실행 환경은 `config/local.json`으로 연결하며 이 파일과 `.runtime/` 모델·벡터 DB·검색 결과는 Git에서 제외합니다.

두 Chroma 컬렉션은 상담 주제 103개와 원문 1,426개에서 만든 검색 레코드 2,091개입니다. 긴 원문만 검색용으로 분할하며 원본 MD는 보존합니다. 검색 CLI는 검색용이며, 챗봇에서는 주제 선별과 근거 기반 답변을 실행합니다. 작성 점검 질문 19개에서 기대 주제가 상위 3개에 포함됐지만, 일반 질문의 1위가 다른 주제인 사례도 있으므로 독립 평가 정확도로 해석하지 않습니다.

## 2026-10-23 2단계: 서비스 지원 범위

메타데이터103개는 보존하며 챗봇 지원101개와 미지원 조사 초안2개를 분리합니다. 재약정 비교(internet_renewal_comparison), 이중계약 피해 상담(internet_sales_dispute)은 대표 공식 근거를 준비 중이므로 선택·자동 추천·직접 요청을 제한합니다. 기존 대화는 열람 가능하며 원본MD는 변경하지 않았습니다. 자동68개/실제HTTP/UI 검증. 재색인 완료, 실행 중 서버는 재시작 필요.
