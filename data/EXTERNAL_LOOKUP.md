# 내부 청크와 외부 조회 기준

자주 필요한 납부방법·계약 변경·가족결합·주요 요금제·공통 할인 조건은 내부 청크로 관리합니다. 특수·기존 요금제, 카드별 상세 조건·월별 프로모션, 실제 제출 양식은 필요한 질문에서 외부 조회합니다. 초기 우선순위이며 실제 사용 로그로 빈도를 측정한 것은 아닙니다.

- 내부 검색으로 정확한 상품과 적용 조건을 식별합니다. 상품이 불분명하면 상품명을 확인합니다.
- 카드·프로모션·특수 상품 질문이거나 내부 근거가 부족하면 [SOURCES.md](SOURCES.md)의 해당 공식 주소를 조회합니다.
- 외부 조회 시 상품명, 적용 대상, 안내 기준일·기간, 예외와 변경/해지 조건을 확인합니다. 오래된 안내나 다른 카드의 조건을 대신 적용하지 않습니다.
- 조회 결과의 직접 명시와 근거를 조합한 판단을 구분합니다. 조회 실패 시 확인하지 못한 조건을 단정하지 않습니다.
- 약관 청크의 이전·다음 링크는 원문 인접 관계입니다. 의미 관계나 할인 유지 보장을 뜻하지 않습니다.
- 반복해서 들어오는 질문에서만 외부 자료를 내부 청크로 승격하고, 그때 출처·범위·검토 상태를 기록합니다.

현재 외부 조회 연결은 문서로 정의한 설계입니다. 챗봇의 실시간 조회 기능을 구현한 상태는 아닙니다.
