# telecom-guide-rag

KT 공식 서비스 안내와 FAQ를 MD 청크로 관리합니다.

- `data/chunks/service_guides/`: 서비스 안내 메뉴별 MD 21개.
- `data/chunks/faq/`: 질문·답변별 MD 1,043개.
- `data/SOURCES.md`: 각 MD의 원본 URL, 분류 경로, 청킹 범위와 수집일.
- `data/raw/`: 기존 공식 PDF 15개(로컬 보관, Git 제외).

FAQ와 서비스 안내는 청크 MD만 보관합니다. 중복 추출 MD·HTML·목록 응답·로컬 이미지는 제거했으며 본문 이미지는 공식 URL을 참조합니다. 원문의 문구·표·조건을 유지하고, 원문의 정책이 현재도 적용되는지 검토하기 전이므로 draft로 관리합니다. 수집일은 시행일을 뜻하지 않습니다. 청크 사이의 의미 관계는 아직 추가하지 않았습니다.

공개 FAQ 11개 분류의 목록 108페이지를 순회했고, 분류별 고유 FAQ 수와 표시 건수가 일치함을 확인했습니다. FAQ 1,043개와 서비스 안내 21개에서 MD 변환 시 본문 텍스트 보존을 확인했습니다. 검증은 추출에 관한 것으로 RAG 검색·답변 정확도 평가와 구분합니다.
