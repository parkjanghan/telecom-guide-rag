# 모바일 멤버십 카드 다운로드 시 가입된 상품이 없습니다라고 나오면서 불가합니다.

분류: 자주하는 질문 > 멤버십 > 가입/카드발급 > 모바일 멤버십 카드 다운로드 시 가입된 상품이 없습니다라고 나오면서 불가합니다.

## 답변

새롭게 휴대폰을 개통하셨거나 번호를 변경하신 경우에는 KT닷컴(www.kt.com) 사이트에서 휴대폰 회선 등록을 추가해 주셔야 정상적으로 모바일카드 발급이 가능합니다.  
KT닷컴에서 회선등록 후 모바일카드를 다운로드 받으시길 바라며, 회선등록 방법은 다음과 같습니다.

☞ KT닷컴 로그인 → 마이 → 가입/이용/해지 → 가입정보변경 → 휴대폰 사용자 등록

위 페이지에서 휴대폰 회선 입력 및 인증번호 인증하시면 간단히 회선 등록 가능합니다.
