# 온라인 즉시납부

분류: 서비스 안내 > 요금납부 > 온라인 즉시납부

즉시납부는 고객님이 원하시는 경우 즉시 출금 및 결제가 가능한 납부방법입니다.  
카카오페이 즉시납부, 네이버페이 즉시납부, 토스페이 즉시납부, 페이코 즉시납부, 간편계좌이체 즉시납부, 실시간 계좌이체 즉시납부, 신용카드 즉시납부, 가상계좌 즉시납부 방법으로 납부 가능합니다.

**표 설명:** 온라인 즉시납부에 대하여 실시간 계좌 즉시납부, 신용카드 즉시납부, 가상계좌 즉시납부로 정리한 표

| 항목 1 | 항목 2 |
| --- | --- |
| 카카오페이 즉시납부 | - ‘카카오톡’ 또는 ‘카카오페이’ 앱을 이용해 요금을 즉시납부 하는 방법입니다.  <br>  (‘카카오톡’ 또는 ‘카카오페이’ 앱 설치 후 이용 가능)<br>- 카카오페이 납부는 선불전자지급수단인 ‘카카오페이 머니/포인트’로만 납부 가능합니다.<br>- ‘카카오톡’ 또는 ‘카카오페이’ 앱에서 요금 납부를 완료하셔야 정상 납부 됩니다.<br>- 자동납부 고객의 경우, 이중납이 발생하지 않도록 출금 일정을 확인 후 신청하시기 바랍니다. |
| 네이버페이 즉시납부 | - ‘네이버’ 앱을 이용해 요금을 즉시납부 하는 방법입니다. (‘네이버’ 앱 설치 후 이용 가능)<br>- 네이버페이 납부는 선불전자지급수단인 ‘네이버페이 머니/포인트’로만 납부 가능합니다.<br>- ‘네이버’ 앱에서 요금 납부를 완료하셔야 정상 납부 됩니다.<br>- 자동납부 고객의 경우, 이중납이 발생하지 않도록 출금 일정을 확인 후 신청하시기 바랍니다. |
| 토스페이 즉시납부 | - ‘토스’앱을 실행하여 요금을 즉시납부 하는 방법입니다.  <br>  (‘토스’앱 설치 후 이용 가능)<br>- 토스페이 납부는 ‘토스페이 머니/계좌결제’로만 납부 가능합니다.<br>- 토스페이 사용자 본인 명의의 요금만 납부 가능합니다.<br>- ‘토스’앱에서 요금 납부를 완료하셔야 정상 납부 됩니다.<br>- 자동납부 고객의 경우, 이중납이 발생하지 않도록 출금 일정을 확인 후 신청하시기 바랍니다. |
| 페이코 즉시납부 | - ‘페이코’ 앱을 실행하여 요금을 즉시납부 하는 방법입니다.  <br>  (‘페이코’ 앱 설치 후 이용 가능)<br>- 페이코 납부는 선불전자지급수단인 ‘페이코 포인트’로만 납부 가능합니다.<br>- ‘페이코’ 앱에서 요금 납부를 완료하셔야 정상 납부 됩니다.<br>- 자동납부 고객의 경우, 이중납이 발생하지 않도록 출금 일정을 확인 후 신청하시기 바랍니다. |
| 실시간 계좌이체 즉시납부 | - 고객님의 계좌에서 원하시는 경우 즉시 출금이 가능한 납부방법입니다.<br>- 납부가능 은행 : 케이뱅크, 국민은행, 기업은행, 농협, 신한은행, 우리은행, 우체국, SC은행, KEB하나은행<br>- KT홈페이지 즉시납부 메뉴에 직접 납부하시거나 KT고객센터 및 KT플라자로 요청하시면 납부 가능합니다.<br>- 유의사항<br>  - 실시간 인출되므로 처리 후 취소 불가합니다<br>  - 대상 요금의 부분 납부 처리 가능하며, 계좌 잔고가 부족 시 출금되지 않습니다.<br>  - 모든 은행(일부 특수, 외국계 은행 제외) 납부하시려면 간편계좌이체로 납부 가능합니다.<br>  - 자동납부 고객의 경우, 이중납이 발생하지 않도록 출금 일정을 확인 후 신청하시기 바랍니다. |
| 신용/체크카드 즉시납부 | - KT 홈페이지에서 회원가입 하신 후 마이 > 요금/서비스 > 요금납부 > 즉시납부 메뉴에서 즉시납부 및 납부결과를 확인할 수 있습니다.<br>- 결제수단 : 모든 신용/체크카드 가능(일부 특수/외국계 은행카드 제외) 신용/체크카드 납부는 KT회원의 본인 카드로 본인 상품에 대해서만 납부가 가능합니다.<br>  단, 타인 카드로 결제를 원하실 경우는 대리점, KT플라자, 고객센터로 신청하셔야 합니다.<br>- 동일 신용/체크카드로 월 10회 이상 납부 또는 충전하실 수 없습니다. (대리점, KT플라자, 고객센터, 웹, 앱 등 모든 수납채널 포함)<br>- 신용/체크카드 납부 시 대상요금의 부분납부 가능하며, 5만원 미만 금액에 대해서는 할부처리가 불가할 수 있습니다. (카드사 할부 기준 적용) |
| 가상계좌 즉시납부 | - 고객님만을 위한 이용요금 납부용으로 제공되는 실제 은행 계좌와 동일한 역할을 하는 가상계좌이며, 이용요금을 가상계좌로 입금하시면 실시간으로 입금확인이 되는 서비스입니다.<br>- 가상계좌번호 확인은 고객님의 명세서나 마이페이지를 통해 확인하실 수 있습니다<br>- 가상계좌 신청 가능 은행 : 케이뱅크, 농협은행, 신한은행, 국민은행, 카카오뱅크, 토스뱅크, 우리은행, 하나은행, 기업은행, 우체국, 부산은행, 경남은행, 광주은행, 전북은행, 아이엠뱅크(구. 대구), SC은행, 한국씨티은행<br>- 유의사항<br>  - 전 은행에서 입금 가능하며, CMS코드를 입력할 필요가 없습니다.<br>  - 전국 모든 은행의 인터넷뱅킹, 스마트뱅킹, CD/ATM입금, 창구입금 모두가능<br>  - 실시간 자동 납부처리<br>  - 지로명세서에 가상계좌 표기 : 납부방법이 "지로"인 고객은 자동부여<br>  - 실제 납부할 금액 초과 이체 시, 입금이 불가합니다.<br>  - 무통장 입금 수수료 : 당행 입금 시 -> 인터넷뱅킹, 스마트뱅킹, CD/ATM 입금 시 무료 (창구 입금은 수수료 부과)<br>  - 타행 입금 시 -> 각 은행별 타행환 수수료 부과<br>  - 가상 계좌번호를 잘못 기재할 경우 다른 고객에게 입금 처리되므로 오기재가 되지 않도록 유의해 주세요. |
| 간편계좌이체 즉시납부 | - ‘금융결제원 인터넷지로 사이트(www.giro.or.kr)’ 연계하여 ‘계좌이체’로 납부하는 방법입니다.<br>- ‘인터넷지로’ 화면에서 요금 납부를 완료하셔야 정상 납부 가능합니다.<br>- 계좌 이체 납부 시 납부자 본인 계좌만 이용 가능합니다.<br>- 자동납부 고객의 경우, 이중납이 발생하지 않도록 출금 일정을 확인 후 신청하시기 바랍니다. |

### 알려드립니다.

- KT의 요금은 후불 납부이며, 매달 납부하시는 이용료를 제외한 요금은 KT의 요청 시 즉시 납부하시거나 별도의 납기일에 입금하셔야 합니다.
