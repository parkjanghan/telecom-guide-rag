# 이심(eSIM) QR 코드를 촬영할 수 없는 상황일 때 어떻게 해야 하나요?

분류: 자주하는 질문 > 휴대폰 > 듀얼번호/eSIM > 이심(eSIM) QR 코드를 촬영할 수 없는 상황일 때 어떻게 해야 하나요?

## 답변

**ㅇ 제조사 : 삼성전자**  
 1. 설정 → 연결 → SIM 관리자 → 모바일 요금제 추가 → 요금제를 자동으로 검색 후 개통회선이 자동 설정됩니다.   
 2. 요금제 자동 설정이 불가능할 경우 : QR 코드 스캔 → 개통코드 입력 → 활성화 코드 'LPA:1$kt.prod.ondemandconnecrivity.com$' 를 입력하시면 요금제가 설정됩니다.   
 3. 약 1~2분 후 SIM 카드 관리자에 이심을 보시면 개통 번호가 보입니다.   
 4. 2분이 지난 후에도 번호가 보이지 않으면 재 부팅을 권장 합니다.   
  
**ㅇ 제조사 : 애플**  
 1. 설정 → 셀룰러 요금제 추가 → 세부내용 직접입력 → SM-DP+주소에 'kt.pord.ondemandconnectivity.com'을 입력합니다.  
 2. 접속 후 셀룰러 요금제 추가 → 셀룰러 요금제 레이블 선택 → 기본/보조회선 선택 → imessage 및 facetime 설정 → 셀룰러 데이터 선택을 하시면 설정이 완료됩니다.
