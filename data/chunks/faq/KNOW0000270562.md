# [KT 패밀리박스] 안심차단 요금제를 사용하는 경우 데이터를 모두 사용한 경우에도  데이터를 꺼내 이용이 가능한가요?

분류: 자주하는 질문 > 혜택 > 패밀리박스 > [KT 패밀리박스] 안심차단 요금제를 사용하는 경우 데이터를 모두 사용한 경우에도  데이터를 꺼내 이용이 가능한가요?

## 답변

네, 데이터 접속이 차단되었더라도 박스에서 데이터를 꺼내시면 꺼낸 데이터량만큼 데이터 접속이 가능합니다.

다만, 데이터 접속이 차단된 상태이므로 와이파이 망에 접속하여 앱을 통해 데이터를 꺼내야 합니다.
