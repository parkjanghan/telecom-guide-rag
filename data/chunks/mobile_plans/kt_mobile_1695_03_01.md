# 키즈 — 데이터 제공

분류: 모바일 > 키즈 > 데이터 제공

- 키즈38 요금제는 기본데이터(5GB)를 모두 사용한 후, 최대 1Mbps 속도로 데이터를 계속 이용할 수 있습니다.
- 키즈28, 키즈24, 키즈20 요금제는 기본데이터를 모두 사용한 후, 최대 400Kbps 속도로 데이터를 계속 이용할 수 있습니다.
- 키즈13 요금제는 데이터 제공량이 없는 안심차단형으로 데이터 사용이 불가합니다.  
  단, ‘데이터 충전’ 신청 시 해당 제공량 안에서 데이터 사용이 가능합니다.
- 본 요금제에 가입된 단말기만 KT WiFi 서비스가 기본 제공됩니다.
