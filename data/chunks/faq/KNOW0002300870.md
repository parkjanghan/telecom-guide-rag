# 주문하는 사람과 실제 휴대폰 명의자가 다를 경우 신청이 가능한가요?

분류: 자주하는 질문 > 휴대폰 > 주문/가입신청 > 주문하는 사람과 실제 휴대폰 명의자가 다를 경우 신청이 가능한가요?

## 답변

주문자와 휴대폰 명의자가 다를 경우 신청이 불가합니다.  
KT닷컴 회원일 경우 로그인 명의자와 가입 신청하는 휴대폰 명의자가 동일해야 하며, 비회원일 경우에는 가입신청 휴대폰 명의자 본인인증을 통해서만 신청이 가능합니다.
