# 3단계 완료 — 탐색 정보와 공식 근거 유형 표시

- 완료일: 2026-10-23 (Asia/Seoul)
- 범위: F2007의 근거 유형 구분 표시 및 F2016의 출처 종류 표시 보완.

## 변경 내용

1. 답변의 ‘탐색용 주제 정보’ 영역에 주제명·설명·범위를 표시하고 ‘공식 정책 근거가 아님’을 명시했다.
2. 주제 메타데이터에는 근거 인용 번호나 공식 원문 링크를 부여하지 않는다. 실제 정책 근거와 별도 객체(topic_context)로 반환한다.
3. 인용한 공식 문서에는 종류·형식·저장/추가조회 구분을 표시한다. 실제 사용한 E번호의 문서만 공식 출처 목록에 남기는 기존 원칙을 유지한다.
4. PDF 쪽 정보가 있는 근거는 쪽수를 표시한다. 일반 PDF는 제목/원본 분류를 확인해 약관 PDF와 구분한다.
5. Markdown 내보내기에도 탐색 정보의 비근거 안내와 문서 유형을 남긴다.
6. 예전 대화에 구분 정보가 없으면 ‘유형 미기록’으로 표시하며 임의로 과거 문서 유형을 만들어 넣지 않는다.

## 분류 기준

모델이 종류를 추측하게 하지 않고 원본의 경로·메타데이터·공식 URL·PDF 정보를 사용한다. 원본 MD를 수정하거나 새로 임베딩하지 않는다. 생성 입력에도 같은 유형 정보를 전달한다.

| 유형 | 현재 원본 수 |
|---|---:|
| 공식 FAQ | 1,043 |
| 공식 서비스 가이드 | 21 |
| 공식 상품 안내 | 196 |
| 공식 할인 안내 | 7 |
| 공식 제휴 혜택 안내 | 22 |
| 공식 약관 PDF | 137 |
| 합계 | 1,426 |

미래의 일반 PDF는 ‘공식 PDF 문서’, 분류할 구체 정보가 없는 웹 자료는 ‘공식 웹 문서’로 표시한다. ‘추가 조회한 공식 자료’라는 표시는 수집 경로를 뜻하며, 내용이 최신 정책으로 보장된다는 뜻은 아니다.

## 검증

- 기존68개 + 신규8개 = 자동 테스트76개 통과.
- 실제 원본1,426개 전체 분류와 원본 SHA-256 보존 확인.
- 약관/일반PDF 구분, 경로가 없는 상품 근거의 원본 메타데이터 참조, 추가조회 자료 표시, 불명 자료의 보수적 분류를 검사했다.
- 메타데이터를 정책 근거로 승격하지 않으며 파일 경로/인용ID/원문URL을 탐색용 정보로 노출하지 않는지 검사했다.
- 생성 결과가 사용하지 않은 문서를 출처로 표시하지 않는지 검사했다.
- JavaScript 문법 검사 통과.
- 실제 GMS 답변과 브라우저에서 탐색 정보의 비근거 고지, 공식 FAQ/서비스 가이드 배지, 공식 링크, 인용 번호→원문 상세 펼치기를 확인했다. 해당 사례의 화면 처리 시간17.06초.
- 상품·약관 PDF 유형은 원본 분류 및 생성 입출력 테스트에서 확인했다. 모든 종류를 인용한 실제 상담을 각각 실행한 것은 아니다. 다양한 답변/옛 대화/페이지 정보 경계 실행은4단계에서 이어간다.

## 적용 및 실행

원본·상담 주제 메타데이터·색인 설정을 변경하지 않았으므로 재색인은 필요 없다. 실행 중인 사용자 서버는 Ctrl+C 후 run-chat.ps1로 재시작하고 브라우저를 새로고침해야 한다.

기존8765서버는 종료하지 않고8766임시 서버에서 검증했다. 임시 서버는 검증 후 종료한다. 커밋·푸시는 하지 않았다.

## 전체 계획 점검

1단계 검색어 생성,2단계 지원 범위,3단계 근거 유형 표시 완료. 다음은4단계 필수 실행·경계 검증이다. 계획 순서는 유지한다.

이 단계로 F2007의 화면 유형 구분 누락과 F2016의 표시 부분을 보완했다. 정확도 전체 검증, 누락 설정/캐시/주제전환 경계, 이용조건과 비교평가/제출 체크리스트가 모두 완료됐다는 뜻은 아니다.
