# 전화를 받을 때 '고객님의 요청으로 음성사서함으로 연결된다'고 나오는 경우 어떻게 해야 하나요?

분류: 자주하는 질문 > 모바일 > 음성통화 > 전화를 받을 때 '고객님의 요청으로 음성사서함으로 연결된다'고 나오는 경우 어떻게 해야 하나요?

## 답변

"고객님의 요청으로 음성사서함으로 연결 중입니다." 라며 수신이 안 될 경우 확인해 보세요.

ㆍ 휴대폰에서 "* + 51 + 통화버튼 + 확인음(딩동댕) + 종료버튼"을 눌러 무조건 음성사서함으로 연결되는 기능을 설정해 놓은 경우입니다.   
  
ㆍ 이 경우, 휴대폰에서 "* +510 + 통화버튼 + 확인음(딩동댕) + 종료버튼"을 눌러 무조건 음성사서함으로 연결되는 기능을 해제하고 전원을 껐다가 켜신 후 이용하시면 됩니다.
