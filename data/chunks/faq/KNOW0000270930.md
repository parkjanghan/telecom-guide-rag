# 휴대폰으로 로밍 이용 시 데이터 이용료가 부과되나요?

분류: 자주하는 질문 > 모바일 > 아이폰 > 휴대폰으로 로밍 이용 시 데이터 이용료가 부과되나요?

## 답변

해외에서 무료 와이파이 지역이 아닌 이동통신망(네트워크)로 데이터 로밍을 사용하실 경우 해당 국가 통신사와의 계약에 따라 국내와는 다른 별도 데이터 로밍 이용료가 발생됩니다.

국내에서 흔히 사용하는 사진/영상 메시지(MMS) 발신 시 동영상, 메일 확인, 인터넷 서핑, 앱 자동 업데이트, 날씨, 주식 확인 등은 모두 데이터 로밍에 해당되며, 역시 국내와 다른 별도의 데이터 이용료가 발생됩니다.

사진/영상 메시지 수신은 무료이며, 발신은 안심 로밍 국가에서는 건당 220원(부가가치세 포함)의 요금이 발생됩니다.
