# [KT 패밀리박스] 데이터 박스에서 꺼낸 데이터 또는 이월 데이터를 박스에 담을 수 있나요?

분류: 자주하는 질문 > 혜택 > 패밀리박스 > [KT 패밀리박스] 데이터 박스에서 꺼낸 데이터 또는 이월 데이터를 박스에 담을 수 있나요?

## 답변

아닙니다. 데이터 담기는 요금제의 이번 달 기본 제공량에서만 가능합니다.

꺼낸 데이터는 '패밀리박스 데이터 100MB/300MB/500MB/1,000MB' 등 데이터 부가서비스 형태로 제공되므로 다시 꺼낼 수 없으며, 다음 달로 넘길 수 없습니다.
