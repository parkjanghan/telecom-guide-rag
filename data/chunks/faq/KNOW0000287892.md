# [휴대폰 가입/기변] 요금 명세서를 확인하고 싶어요.

분류: 자주하는 질문 > 기타 > 기타 > [휴대폰 가입/기변] 요금 명세서를 확인하고 싶어요.

## 답변

명세서 유형에 따라 확인 방법이 달라집니다.  
  
[kt.com웹명세서]  
ㆍ 매월 15일 KT닷컴 및 마이케이티 앱에서 확인 가능한 온라인 명세서  
  
[이메일 명세서]  
ㆍ 매월 10~13일경 이용 요금 명세서를 암호화(PDF)하여 이메일로 발송  
  
[모바일 명세서]  
ㆍ 매월 10일부터 명세서 발송  
  
     1. RCS 버전  
    ㆍ 웹 형태의 최신 UI 제공  
    ㆍ 휴대폰에서 채팅+를 켜시면 RCS버전의 모바일명세서를 받아보실 수 있습니다.(애플 운영 체제(iOS) 제외)  
     ☞ 설정 방법 : 문자 → 우측상단 점 3개 → 설정 → 채팅+설정 → 채팅+관리 → 채팅+ 켜기  
  
    2. MMS 버전  
    ㆍ 명세서 이미지와 함께 사진/영상 메시지(MMS)로 발송  
  
[우편 명세서]  
ㆍ 매월 11~15일경 명세서를 우편으로 발송  
ㆍ 영문/실버/점자 명세서 신청 가능  
  
▶ 명세서 발송 일정은 공휴일등 사정에 의해 변동될 수 있음
