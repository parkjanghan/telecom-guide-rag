# 사용중인 휴대폰이 2년이 넘었는데 자동으로 요금할인이 제공되나요?

분류: 자주하는 질문 > 모바일 > 스폰서 > 사용중인 휴대폰이 2년이 넘었는데 자동으로 요금할인이 제공되나요?

## 답변

선택약정(요금할인)은 약정할인으로 가입을 하셔야 할인 혜택을 받으실 수 있습니다.  
  
아래 경로를 통해 가입해 주시기 바랍니다.  
ㆍ KT닷컴 → 마이 → 가입/이용/해지 → 가입정보 변경 → 요금할인 재약정  
[☞ 바로가기 클릭](https://my.kt.com/contract/MoPhoneApplicationInfo.do)  
ㆍ 마이케이티 앱 → 메뉴 → 마이 → 가입/이용/해지 → 가입정보 변경 → 요금할인 재약정
