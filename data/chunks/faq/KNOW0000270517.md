# [KT 패밀리박스] 데이터 담기할 때 왜 500MB가 남아있어야 하나요?

분류: 자주하는 질문 > 혜택 > 패밀리박스 > [KT 패밀리박스] 데이터 담기할 때 왜 500MB가 남아있어야 하나요?

## 답변

데이터 박스에 담겨지는 데이터는 실제 전산 시스템에 반영되기까지 몇 분의 시간이 소요됩니다.

만약, 500MB의 잔여량 제한없이 모두 담기 가능하다면 전산 시스템에서 개인 계정의 데이터를 박스로 담는 작업이 완료되기 전 데이터 담기로 인해 실제 잔여 데이터량이 없음에도 데이터를 사용하여 요금이 초과하여 발생할 수 있으므로 이를 방지하기 위해 잔여량 500MB를 남겨두는 것입니다.
