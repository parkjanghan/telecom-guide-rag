# 자동납부

분류: 서비스 안내 > 요금납부 > 자동납부

자동납부는 간편결제 자동납부, 신용카드 자동납부, 은행 자동납부 방식으로 납부 가능합니다.

## 간편결제 자동납부

간편결제 자동납부는 카카오페이 머니/포인트 또는 네이버페이 머니/포인트, 토스페이 머니/계좌결제, 페이코 포인트를 이용해 요금을 납부하는 방식입니다.

**표 설명:** 사용가능 앱, 신청방법, 유의사항의 순서로 카카오페이 자동납부 설명표

| 항목 1 | 항목 2 |
| --- | --- |
| 사용가능 앱 | - ‘카카오톡’ 또는 ‘카카오페이’ 앱<br>- ‘네이버’ 앱<br>- ‘토스’ 앱<br>- ‘페이코’ 앱 |
| 신청방법 | - 고객센터, KT플라자 또는 대리점으로 전화 또는 방문 신청하시면 됩니다.<br>- 또는 마이 > 요금/서비스 > 요금납부 > 납부방법 변경에서 신청/변경하시면 됩니다. |
| 유의사항 | - 카카오페이 자동납부<br>  - 상품 가입 명의자의 카카오페이로만 납부 가능하며, 자동납부 신청 시 선불전자지급수단인 ‘카카오페이 머니/포인트’ 로  <br>    납부하실 수 있습니다.<br>  - ‘카카오톡’ 또는 ‘카카오페이’ 앱에서 자동납부 신청을 완료하셔야 정상처리 됩니다.<br>- 네이버페이 자동납부<br>  - 상품 가입 명의자의 네이버페이로만 납부 가능하며, 자동납부 신청 시 선불전자지급수단인 ‘네이버페이 머니/포인트’로  <br>    납부하실 수 있습니다.<br>  - 네이버페이로 이동하여 자동납부 신청을 완료하셔야 정상처리 됩니다.<br>- 토스페이 자동납부<br>  - 상품 가입 명의자의 토스페이로만 납부 가능하며, 자동납부 신청 시 ‘토스페이 머니/계좌결제’로 납부하실 수 있습니다.<br>  - ‘토스’ 앱에서 자동납부 신청을 완료하셔야 정상처리 됩니다.<br>- 페이코 자동납부<br>  - 상품 가입 명의자의 페이코로만 납부 가능하며, 자동납부 신청 시 선불전자지급수단인 ‘페이코 포인트’ 로  <br>    납부하실 수 있습니다.<br>  - ‘페이코’ 앱에서 자동납부 신청을 완료하셔야 정상처리 됩니다.<br>- 21일/25일 미 승인된 건에 대해서는 말일경 추가 승인 진행됩니다. |

## 신용카드 자동납부

신용카드 자동 납부는 월 사용요금을 KT에서 신용카드사로 청구하면 고객님께서 신용카드사에 결제대금(월 사용요금)을 납부하시는 제도입니다.

**표 설명:** 신용카드 자동납부에 대하여 사용가능 카드, 신청방법, 유의사항으로 정리한 표

| 항목 1 | 항목 2 |
| --- | --- |
| 사용가능 카드 | - 신용/체크카드 가능(일부 특수/외국계 카드 제외) |
| 신청방법 | - 고객센터, KT플라자 또는 대리점으로 전화 또는 방문 신청하시면 됩니다.<br>- 또는 마이 > 요금/서비스 > 요금납부 > 납부방법 변경에서 신청/변경하시면 됩니다. |
| 유의사항 | - 유효기간 만료, 분실/파손 등으로 카드를 재발급 받으시면 반드시 재발급 받은 카드로 변경 신청하여 주십시오.<br>- 신용/체크카드의 납기일은 매월1차(11일), 2차(19일) 중에 선택하실 수 있습니다.<br>  - 선택한 납기일이 휴일인 경우에는 다음 영업일에 승인됩니다.<br>  - 자동납부 자료 전송 및 처리과정에서 카드사마다 실제 승인일은 다를 수 있습니다.<br>- 고객님의 사정으로 선택하신 납기일에 정상적인 승인이 되지 않을 경우, 다음 납기일에 승인될 수 있습니다.<br>  - 1차(11일), 2차(19일)에 승인이 되지 않은 경우 25~27일 경에 추가 승인될 수 있습니다. |

## 은행 자동납부

은행 자동 납부는 고객의 예금계좌에서 매월 납기일에 요금이 자동으로 출금되어 납부되는 제도입니다.

**표 설명:** 은행 자동납부에 대하여 납부가능 은행, 신청방법, 유의사항으로 정리한 표

| 항목 1 | 항목 2 |
| --- | --- |
| 납부가능 은행 | - 전국 모든 은행(일부 특수, 외국계 은행제외) |
| 신청방법 | - KT 고객센터로 전화신청 또는 KT플라자, 대리점으로 전화 또는 방문 신청하시면 됩니다.<br>- 또는 마이 > 요금/서비스 > 요금납부 > 납부방법 변경에서 신청/변경하시면 됩니다.  <br>  * 단, 마이페이지에서 신청/변경 시 본인 인증 후 자동이체로 변경 가능합니다. |
| 유의사항 | - 은행 자동납부는 납기일을 18일, 21일, 25일 중 선택하실 수 있으며, 납기일 전에 거래은행 통장의 잔고를 확인하시기 바랍니다.<br>- 납기일에 출금되지 않는 경우 익월 납기일까지 1~5회 추가로 출금되므로, 잔액을 유지하시면 납기일 이후에도 자동 출금되어 편리합니다.<br>- 수출입은행/HSBC/신용보증기금/기술신보/교보증권/이트레이드증권/솔로몬투자증권/LIG투자증권 계좌로의 자동이체 등록은 불가능합니다.<br>- 자동납부 변경 가능 시간은 평일 8시 50분 ~ 21시 55분이며 평일 야간/공휴일은 예약 대기상태 후 다음 영업일에 자동으로 반영됩니다. |

### 유의사항 안내

- KT의 요금은 후불 납부이며, 매달 납부하시는 이용료를 제외한 요금은 KT의 요청 시 즉시 납부하시거나 별도의 납기일에 입금하셔야 합니다.
