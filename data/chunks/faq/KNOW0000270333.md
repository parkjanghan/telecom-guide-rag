# [인터넷전화 착신통화전환] 서비스란?

분류: 자주하는 질문 > 인터넷전화 > 통화서비스 > [인터넷전화 착신통화전환] 서비스란?

## 답변

부재중에도 걸려 오는 전화를 다른 전화기로 전환해 주는 서비스입니다.  
  
ㆍ 요금 : 월 550원(부가가치세 포함)  
  
ㆍ 설정 방법  
- 착신전환 설정 : *  → 88 + 착신희망번호 → * → 통화  
- 무응답(15초)/통화 중 착신전환 : * → 84 + 착신희망전화번호  → * → 통화  
- 통화/데이터 연결이 안 되는 지역 자동착신 전환 : * → 85 + 착신희망전화번호 → * → 통화  
- 착신전환 취소(위 3가지 취소 방법) : # → 88 → * → 통화  
- 착신전화상태 확인 : * → 83  → * → 통화  
  
▶ 설정 시 지정한 번호까지 연결 통화 요금은 별도로 발생됩니다.
