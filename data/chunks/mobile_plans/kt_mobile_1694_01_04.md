# 베이직(이월) — 상품 상세 안내 > 데이터 제공

분류: 모바일 > 베이직(이월) > 상품 상세 안내 > 데이터 제공

## 데이터 제공

- 이번 달 기본 데이터 중 남은 데이터는 다음 달로 자동 이월 됩니다.
  - 이번 달 사용하고 남은 데이터는 다음달까지 사용하실 수 있습니다. (예. 2월에 남은 데이터는 3월로 이월되며, 3월까지 사용 가능)
  - 이월 데이터는 이번 달 기본 데이터보다 우선 사용(차감) 됩니다.
  - 이월 데이터가 남아 있는 상태에서 베이직(이월) 외 요금제로 변경 시, 이월 데이터는 소멸되어 이용하실 수 없습니다.​
- 월 제공 데이터는 1개월 중 가입되어 있는 일수에 따라 일할 계산되어 제공 됩니다.
- 당월 월제공 데이터 소진 또는 월중 요금제 변경/해지 시, 일할 계산된 제공량을​ 초과하는 경우 아래와 같이 요금(부가세 포함)이 발생합니다.​
  - 1구간 : 15,000원 까지 0.011원/0.5KB로 사용(약0.67GB)
  - 2구간 : 추가요금 없이 3GB까지 사용
  - 3구간 : 3GB부터 200Kbps로 속도 제어 (속도 제어 해제 시 0.011원/0.5KB로 사용 가능하며, 최대 100,000원까지 요금 발생)

- 스마트기기 공유데이터는 기본 데이터 내 이용 가능하며, 기본 데이터 소진 후 200Kbps로 속도 제어 됩니다.
