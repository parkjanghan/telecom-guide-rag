# 유심(USIM)에 설정한 PIN번호 확인은 어떻게 해야 하나요?

분류: 자주하는 질문 > 모바일 > 서비스정책 > 유심(USIM)에 설정한 PIN번호 확인은 어떻게 해야 하나요?

## 답변

유심(USIM)에 설정한 PIN번호를 3회 연속으로 잘못 입력하면 잠길 수 있으므로 입력은 주의깊게 해주셔야 합니다.  
  
PIN을 3회 연속 잘못 입력한 경우에는 유심 잠금 해제 번호(PUK) 번호를 조회하여 재설정이 필요합니다.  
  
■ 유심 잠금 해제 번호를 알고 있는 경우  
ㆍ 휴대폰에서 직접 번호 입력하여 PIN재설정이 가능합니다.  
 - PIN 3회 오입력 → PUK잠김 → PUK번호입력 → PIN재설정  
 - 휴대폰에서 PUK번호 입력 시 입력 횟수 카운팅되며, 횟수는 휴대폰 액정에 팝업됩니다.  
  
■ 유심 잠금 해제 번호를 모르는 경우 (KT닷컴 또는 플라자 방문 필요)  
☞ KT닷컴 → 마이 → 가입/이용/해지 → 가입정보 → USIM PIN 초기화 비밀번호  
- 본인 인증(신용카드, 카드사 홈페이지, 아이핀 중 택 1) 후 처리 가능  
  
※ PIN 초기 번호는 0000 입니다.
