# [애플워치] 기존과 동일하게 사용 중에 명의변경은 안되는 게 맞는지요?

분류: 자주하는 질문 > 워치/태블릿/에그/스마트기기 > 워치 개통/연동 > [애플워치] 기존과 동일하게 사용 중에 명의변경은 안되는 게 맞는지요?

## 답변

사용중 명의변경은 가능하지만, 명의변경 과정에서는 사용 중인 이심(eSIM)을 그대로 사용하므로 비용은 부과되지 않습니다.

하지만 워치 기기 데이터 초기화 시(설정>일반>초기화) 네트워크 초기화 버튼을 누르지 말고 다름 단계로 이동해야 하며 네트워크 초기화할 경우 이심 프로파일 정보가 삭제되어 재등록할 때 설치비가 추가 발생되며, 이심도 초기화를 원할 경우에도 설치비가 추가 발생됩니다.
