# 중고폰이나 자급제로 이심(eSIM)을 개통하려고 하는데 IMEI를 입력하라고 합니다. IMEI는 어떻게 확인하나요?

분류: 자주하는 질문 > 휴대폰 > 듀얼번호/eSIM > 중고폰이나 자급제로 이심(eSIM)을 개통하려고 하는데 IMEI를 입력하라고 합니다. IMEI는 어떻게 확인하나요?

## 답변

휴대폰 식별 번호(IMEI)는 15자리 숫자로 조합되어 있으며 제조사별로 확인하는 방법이 다릅니다.   
ㅇ 삼성전자 : 설정 → 폰 정보 →  IMEI 1 / IMEI 2 이심(eSIM)으로 구분되어 확인 가능합니다.   
ㅇ 아이폰 : 설정 → 일반 → 정보 →  사용중인 SIM / 사용 가능한 SIM의 IMEI 확인 가능합니다.
