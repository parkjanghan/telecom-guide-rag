# 가입신청 구비서류 안내

분류: 서비스 안내 > 상품가입 > 가입신청 구비서류 안내

가입비, 통화료 할인 등 계약관계에 있어서 기본적인 사항을 확인하는 것이므로 구비서류를 제시하여 관련사항에 대한 혜택을 받을 수 있도록 준비하여 주시기 바랍니다.

[국가유공자 할인 증빙서류 자세히 보기](#popup-1)

## 일반

**표 설명:** 방문자, 구비서류의 순서로 [일반] 구비서류 정보표

| 방문자 | 구비서류 |
| --- | --- |
| 본인 | - 명의자 신분증 |
| 대리인 | - 명의자 신분증, 명의자 인감증명서, 명의자 인감도장이 날인된 위임장, 대리인 신분증 |

## 미성년자

**표 설명:** 방문자, 구비서류의 순서로 [미성년자] 구비서류 정보표

| 방문자 | 구비서류 |
| --- | --- |
| 본인 | - 본인 신분증, 법정대리인 가입동의서, 인감증명서 및 법정대리인 입증서류(가족관계 증명서 및 기본증명서 등)<br>- 미성년자 부모확인서비스 통해 부모-자녀 관계 확인 시 법정대리인 입증서류 제출 불필요 |
| 법정대리인 | - 법정대리인 신분증, 법정대리인 가입동의서, 법정대리인 입증서류(가족관계 증명서 및 기본증명서 등)<br>- 미성년자 부모확인서비스 통해 부모-자녀 관계 확인 시 법정대리인 입증서류 제출 불필요 |
| 대리인 | - 대리인 신분증, 법정대리인 가입동의서, 법정대리인 위임장(인감날인), 법정대리인 인감증명서 및 법정대리인 입증서류 (가족관계증명서 및 기본증명서 등)<br>- 미성년자 부모확인서비스 통해 부모-자녀 관계 확인 시 법정대리인 입증서류 제출 불필요 |

- 18세 미만 미성년자의 본인 신분증은 주민등록번호가 표기된 학생증 및 청소년증에 한하며 주민등록번호가 표기되지 않은 미성년자의 학생증 및  
  청소년증은 주민등록번호가 표기된 주민등록등본, 가족관계증명서, 기본증명서, 재학증명서, 재직증명서 등 다른 서류와 조합하여 신분증으로 이용 가능
- 18 세 이상 미성년자인 대학생/직장인의 경우, 재학증명서(학생증)나 재직증명서 제출시 법정대리인 인감증명서 제외

## 외국인

**표 설명:** 방문자, 구비서류의 순서로 [외국인] 구비서류 정보표

| 방문자 | 구비서류 |
| --- | --- |
| 본인 | - 명의자 외국인등록증 |
| 대리인 | - 명의자 외국인등록증, 여권, 명의자 서명이 된 동의서(여권서명과 동일), 대리인 신분증 |

## 개인사업자

**표 설명:** 방문자, 구비서류의 순서로 [개인사업자] 구비서류 정보표

| 방문자 | 구비서류 |
| --- | --- |
| 대표자 | - 명의자 신분증, 사업자등록증 사본 |
| 대리인 | - 명의자 신분증, 사업자등록증 사본, 명의자 인감 증명서, 인감도장 날인된 위임장, 대리인 신분증 |

## 법인

**표 설명:** 방문자, 구비서류의 순서로 [법인] 구비서류 정보표

| 방문자 | 구비서류 |
| --- | --- |
| 대표자 | - 대표자 신분증, 사업자등록증 사본/법인등기부등본/사업자등록증명원 중 택 1 |
| 대리인 | - 대리인 신분증, 사업자등록증 사본, 법인 인감증명서, 법인 인감도장이 날인된 위임장 또는 공문 |

## 국가기관

**표 설명:** 방문자, 구비서류의 순서로 [국가기관] 구비서류 정보표

| 방문자 | 구비서류 |
| --- | --- |
| 대리인 | - 사업자등록증, 기관장명의 위임공문, 대리인 신분증 |

### 알려드립니다.

- 구형 운전면허증(2002년 6월 30일 이전발급)은 고객 신분 확인용으로 사용 불가
- 가족증명서류 : 주민등록등본, 가족관계증명서, 가족관계가 명시된 의료보험증(2003년 이전 발급된 의료보험증만 가족관계 명시됨)
- 주민등록등본, 위임장, 인감증명서는 신청일로부터 3개월 이내 발급된 증명서만 인정
- 단, 공공법인일 경우 법인인감증명서 대신 위임 공문으로 대체 가능(예:한국가스공사 등)
- 법인 대리인은 해당 법인 직원에 한함
