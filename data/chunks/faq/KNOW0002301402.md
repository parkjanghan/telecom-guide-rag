# 듀얼SIM에서의 데이터 이용 방식이 궁금합니다.

분류: 자주하는 질문 > 휴대폰 > 듀얼번호/eSIM > 듀얼SIM에서의 데이터 이용 방식이 궁금합니다.

## 답변

데이터 지정 회선의 데이터만 소모되며, 지정되지 않은 최선의 데이터는 소모되지 않습니다.  
단, 통화 중인 경우 통화 회선이 아닌 다른 듀얼 회선의 데이터 이용이 불가합니다. (데이터 메뉴 내'셀룰러 데이터 전환 허용' 권장)"
