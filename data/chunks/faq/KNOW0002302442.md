# 케이득 친구추천 혜택은 어떻게 받을 수 있나요?

분류: 자주하는 질문 > iPhone Duo 사전예약 > 사전예약 혜택 > 케이득 친구추천 혜택은 어떻게 받을 수 있나요?

## 답변

케이득 친구추천 혜택을 받으시려면 친구추천 코드를 발급받은 후, 사전예약 신청서 작성 시 친구추천 코드를 입력해 주세요.  
  
친구추천 코드를 입력하고 개통을 완료한 고객에 한해 개통 익월 말에 혜택이 제공됩니다.  
  
신청서 작성 시 친구추천 코드를 입력하지 않은 경우 혜택이 제공되지 않습니다. 코드 입력을 위해서는 기존 신청서를 취소한 후 다시 작성해야 하며, 이 경우 기존 사전예약 접수도 취소되어 배송이 지연되거나 선착순 혜택 대상에서 제외될 수 있으니 유의해 주세요.
