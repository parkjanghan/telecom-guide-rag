# telecom-guide-rag

- `data/raw/`: 공식 PDF 원본 15개.
- `data/raw/service_guides/`: 현재 서비스 안내 메뉴 전체 21개 항목의 원문 HTML.
- `data/raw/service_guides/assets/`: 본문 이미지 8개.
- `data/extracted/service_guides/`: 서비스 안내 본문 MD 21개.
- `data/chunks/service_guides/`: 메뉴 항목 하나당 청크 하나인 MD 21개.
- `data/SOURCES.md`: PDF·서비스 안내·본문 이미지의 원본 URL과 저장 파일 대응표.

서비스 안내는 상품가입 2개, 상품변경 8개, 상품해지 2개, 요금납부 8개, 요금명세서 1개입니다. 본문·표 39개·유의사항·팝업 보충 안내를 보존하고 공통 메뉴·푸터를 제외했습니다. 병합 셀은 적용 행·열에 내용을 반복해 MD 표로 변환했습니다.

각 청크에 분류 경로, 문서 ID, 원문 파일, 수집일과 검수 상태를 기록했습니다. 추출 본문 보존은 확인했으며 정책 적용 범위에 대한 검토는 별도이므로 draft 상태입니다. 수집일은 시행일을 의미하지 않습니다. 원문의 오류나 과거 안내는 임의로 고치지 않았습니다.

기존 PDF의 전체 청킹은 아직 하지 않았습니다. 웹페이지에서 변환한 MD는 공식 배포 MD 원본과 구분합니다. 청크 간 의미 관계는 아직 추가하지 않았습니다.

- `data/chunks/faq/`: FAQ ID 하나당 청크 하나인 MD 1,043개.

공개된 11개 분류 전체와 Top 10을 확인했습니다. 각 분류의 목록 고유 ID 수와 사이트 표시 건수를 대조했고 수집 중 표시 건수 변화도 없었습니다. Top 항목은 같은 FAQ ID를 중복 청크로 만들지 않습니다. 질문·답변 전체, 분류 경로, 표·유의사항·링크를 유지합니다. 추출 검증과 정책·검색 품질 검토는 별개이며 청크는 draft입니다. 임의의 청크 간 의미 관계는 추가하지 않았습니다.
