# [인터넷]의 속도를 확인하고 싶은데 방법이 있는지 알려주세요.

분류: 자주하는 질문 > 인터넷 > 이용안내 > [인터넷]의 속도를 확인하고 싶은데 방법이 있는지 알려주세요.

## 답변

사용하시는 인터넷의 속도는 KT닷컴에서 측정 가능합니다.  
  
☞ KT닷컴 → 고객지원 → 셀프진단∙A/S신청 → 인터넷 속도측정  
 [☞ 속도 테스트 바로가기 클릭](https://speed.kt.com/speed/speedtest/introduce.asp)

단, 한 번의 측정 결과로는 정확한 판단이 어렵사오니 시간대를 변경하시어 여러 번 테스트 해주시기를 부탁 드립니다.

※ 메모리 점유율이나 CPU 부하율이 큰 상태에서는 속도가 비교적 낮게 측정될 수 있으므로 실행 중인 프로그램이 있다면 모두 종료하시고 측정하시는 것을 권장해 드립니다.
